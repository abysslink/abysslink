| Boundary | Description |
|----------|-------------|
| CLI args → WoL send | rig name is user-supplied; MAC comes from trusted config, not argv |
| UDP broadcast → LAN | 255.255.255.255:9 is LAN-limited by OS routing; no internet traversal |
| Audit log | MAC written as content (hashed only); not a secret but recorded for accountability |
