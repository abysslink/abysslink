## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI → NetBird REST API | API key from env (ABYSSLINK_NB_API_KEY); never on argv or in logs |
| Posture check JSON body | User-supplied --checks flag value is raw JSON; passed as json.RawMessage without shell interpolation |
| Events polling | All events from GET /api/events/audit; no private event data exposed beyond what the API returns |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-04-01 | Information Disclosure | NetBird API key in logs/argv | mitigate | API key flows only through Authorization: Token header inside doRequest; never to slog, argv, or audit log (existing T-13-02 control) |
| T-21-04-02 | Tampering | posture create/delete without audit | accept | Posture management calls are logged by NetBird's own audit events (visible via events command); no additional audit.WriteFile needed as posture config lives server-side |
| T-21-04-03 | Tampering | --checks JSON injection | mitigate | --checks value is passed as json.RawMessage; the NetBird API validates the JSON structure; no shell interpolation (discrete argv, no sh -c) |
| T-21-04-04 | Elevation of Privilege | events --follow starves context | mitigate | Bounded backoff caps at 30s; ctx.Done() exits cleanly; ticker.Stop() in defer |
| T-21-04-SC | Tampering | npm/pip/cargo installs | accept | No new package manager installs in this plan |
