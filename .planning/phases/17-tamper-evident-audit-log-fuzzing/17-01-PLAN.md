<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| keychain → audit package | HMAC key fetched from OS keychain; must not be logged or returned in error messages |
| audit log file (disk) → verifier | Log is read from disk; any line could be tampered by a local attacker with fs write access |
| HMAC signing input → Entry fields | SignInput is the only path to the signer; must not accept body/content/data/raw fields |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-01 | Tampering | audit.log JSONL entries | mitigate | SHA-256 hash chain: any deletion or modification of entry[i] breaks entry[i+1].prev_hash; Verify() detects and reports at exact entry index |
| T-17-02 | Tampering | audit.anchor.json | mitigate | Anchor is itself HMAC-signed (anchorSignBytes covers entry_count + last_hash + time); VerifyAnchor uses hmac.Equal (constant-time) |
| T-17-03 | Tampering | Audit log truncation | mitigate | anchor.EntryCount field; Verify() sets TruncationDetected when current count < anchor.EntryCount |
| T-17-04 | Information Disclosure | HMAC key via error messages | mitigate | hmacKey() wraps errors with fmt.Errorf; never interpolates key bytes into error strings; key only held in []byte in function scope |
| T-17-05 | Information Disclosure | Secret body in audit log | mitigate | AUD-04: SignInput type-restricted to Title string + DiffHash [32]byte; forbidigo lint rule blocks future field additions; computeSig receives fixed-layout struct |
| T-17-06 | Information Disclosure | Timing oracle on HMAC compare | mitigate | verifyHMAC uses hmac.Equal (constant-time, documented in crypto/hmac); bytes.Equal is forbidden (RESEARCH.md anti-patterns) |
| T-17-07 | Spoofing | Chain fork under concurrent append | mitigate | mu.Lock() held across full readLastNonEmptyLine → computePrevHash → computeSig → os.OpenFile → f.Write sequence; 50-goroutine stress test with -race validates this |
| T-17-08 | Denial of Service | HMAC key absent / keychain unavailable | mitigate | NewSigned fails closed (returns error); caller (daemon, up --apply) must surface error; FATAL doctor check audit-keychain (Plan 02) reports missing keychain |
| T-17-SC | Tampering | No new package installs in this plan | accept | All crypto/stdlib; no supply-chain risk; no npm/pip/cargo installs |
</threat_model>
