<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI user input → audit verify exit code | Exit code 2 must only be set on genuine chain break, not on file-not-found or parse errors |
| daemon → anchor write cadence | Hourly anchor goroutine must not block the daemon's shutdown path; context cancellation must propagate |
| doctor findings → secrets (kc) | Doctor checks call NewSigned to probe keychain availability; must not log the key value |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-09 | Tampering | `abysslink audit verify` exit code | mitigate | Only Verify()'s VerifyResult.OK==false or TruncationDetected sets exit 2; parse errors return exit 1 (generic error), not 2 |
| T-17-10 | Information Disclosure | audit-keychain doctor check error message | mitigate | Finding.Message describes the failure class (keychain unavailable), not the key material; NewSigned error is wrapped, not the raw key |
| T-17-11 | Denial of Service | Hourly anchor goroutine blocking on stuck keychain | mitigate | WriteAnchor call uses ctx with timeout (ctx with 30s deadline derived from the parent ctx); slog.Warn on timeout and continue |
| T-17-12 | Repudiation | backup verify bypasses chain check | mitigate | backup verify calls audit.Verify (same function as audit verify) — identical verification logic, not a separate weaker path |
| T-17-13 | Spoofing | audit-count-vs-anchor FATAL with zero-entry new log | accept | New installations have no anchor yet; check only fires when anchor exists AND count < anchor.EntryCount; zero-anchor state emits WARN not FATAL |
| T-17-SC | Tampering | No new package installs in this plan | accept | No npm/pip/cargo/go-get new packages; all stdlib + existing deps |
</threat_model>
