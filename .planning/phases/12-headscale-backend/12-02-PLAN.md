<objective>
Implement the headscaleAdapter struct that plugs into the Phase 11 backend.Client seam, covering the three sub-interfaces required by HS-01: Client (Status/IP/Hostname/Up/Down), AdminAPI (Devices/TagDevice/DeleteDevice/CreateAuthKey), and ACLManager (GetACL/SetACL/NewACLEditor/DefaultACL/Diff). Add the factory case and the full contract + lockstep invariant test suite.

Purpose: This is the core client-side backend integration for HS-01. Modules that type-assert AdminAPI or ACLManager against this adapter gain full Headscale REST control-plane access. The Locker sub-interface is intentionally NOT implemented — the lockstep invariant test enforces this permanently.

Output: headscale.go (adapter), headscale_test.go (contract + invariant + deny-all baseline tests), factory.go (extended switch). All three backed by the httptest fixtures from Wave 1.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| headscaleAdapter → Headscale REST API | Bearer API key over TLS; key loaded from OS keychain only |
| headscaleAdapter.Up() → tailscale binary | Pre-auth key injected via TS_AUTHKEY env; never on argv |
| test mock → headscaleAdapter | httptest server; fixture data only; no real credentials |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-02-01 | Information Disclosure | headscaleAdapter.doRequest() API key | mitigate | Key loaded via apiKey func() from keychain only (D-10); set only in Authorization header inside doRequest(); never passed to slog.*, audit.Append, or any argv; CLAUDE.md hard rule |
| T-12-02-02 | Information Disclosure | headscaleAdapter.Up() pre-auth key | mitigate | Key passed via env map TS_AUTHKEY to RunWithEnv — never on argv (D-11); never logged; bcrypt-hashed server-side after v0.28.0 so re-reading is impossible |
| T-12-02-03 | Elevation of Privilege | headscaleAdapter.Capabilities().Lock=false | mitigate | LockCapability() returns LockNone; adapter does NOT implement Locker; invariant test fails build if drift occurs; hs-lock permanent WARN fires in doctor (Wave 3) |
| T-12-02-04 | Spoofing | TLS verification skip in net/http | mitigate | http.DefaultClient uses system TLS roots; TLS cert gate enforced at init time (Wave 4); never use InsecureSkipVerify |
| T-12-02-05 | Elevation of Privilege | deny-all ACL baseline ordering | mitigate | Up() calls SetACL(deny-all) after tailscale up succeeds, before returning — no window where a node is admitted without policy per HS-01 SC-1 |
| T-12-02-06 | Elevation of Privilege | Pre-auth key without expiry (issue #1579) | mitigate | CreateAuthKey always sets Expiration = time.Now().Add(preAuthKeyExpiry); test asserts non-zero expiry in POST body |
| T-12-02-SC | Tampering | npm/pip/cargo installs | accept | No new external package installs in this plan |
</threat_model>
