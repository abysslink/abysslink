Extend the existing abysslink init wizard to offer backend.type: headscale as an option alongside the default Tailscale backend (ROADMAP SC-1 / D-13).

Purpose: Without this extension, users who want to use a self-hosted Headscale control plane must manually edit abysslink.yaml after init. SC-1 requires the wizard to accept the headscale backend choice interactively. The default Tailscale path is unaffected.

Output: cmd_init.go with two targeted additions to runInitForm(): (1) a huh.NewSelect prompt for backend type, (2) a conditional huh.NewInput prompt for the Headscale server_url shown only when headscale is selected. The generated config reflects the choice.
</objective>
