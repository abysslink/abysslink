<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| daemon → abysslink binary (shell.Runner) | Digest calls the sibling abysslink binary via runner.Run — argv must be discrete (no sh -c) |
| report output → caller (human or CI pipeline) | report JSON must not leak hostname/IP/node_id in RigID fields |
| metrics doctor → net.DialTimeout | The probe dials the configured port — could surface an error if the port is legitimately busy |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-11 | Information Disclosure | sendDigest notification body | mitigate | Per-rig identifiers in digest payload are always OpaqueRigLabel(rig.Name) — 16-char hex, no raw rig.Name / Hostname / NtfyTopic exposed to the Notifier |
| T-18-12 | Tampering | Digest binary path injection | mitigate | resolveAbysslink uses os.Executable() sibling path (absolute, from the OS) then exec.LookPath; never reads the path from user-controlled config or environment |
| T-18-13 | Information Disclosure | report --all-rigs RigResults JSON | mitigate | rigReachability.RigID is OpaqueRigLabel(rig.Name); Hostname, Name, NtfyTopic are not in the JSON output |
| T-18-14 | Denial of Service | met-cardinality probe in doctor | accept | Doctor runs on-demand by the user; the probe is a read-only Snapshot() call; no write path; cardinality counting is O(n) over existing metric families only |
| T-18-15 | Tampering | met-disabled-listener false-positive | accept | net.DialTimeout with 200ms timeout may trigger a false FATAL if a non-abysslink process happens to bind the same port; message includes "stale listener" guidance so the user can investigate |
| T-18-SC | Tampering | npm/pip/cargo installs | accept | No new external packages introduced |
</threat_model>
