In Go, an interface value is nil only when both its type and value pointers are nil; the correct check for a nil interface is `if b == nil`. Write: if b == nil { slog.Error("abysslinkd: metrics: no backend client; metrics listener disabled"); return }. This guard MUST appear before any call to b.IP(ctx) to prevent a nil-interface-method panic (CLAUDE.md: no panics in normal control flow).

    After the nil guard: (1) call ip, err := b.IP(ctx); on error log slog.Error("abysslinkd: metrics: resolve tailnet IP", "err", err) and return without panicking; (2) build addr as ip + ":" + port where port is cfg.Observability.Metrics.Port if > 0, else 9090; (3) call net.Listen("tcp", addr); on error slog.Error and return; (4) build an http.NewServeMux, register metricsHandler(reg) on GET /metrics; (5) create http.Server with Handler and ReadHeaderTimeout of 5 seconds; (6) launch srv.Serve(ln) in a nested goroutine ignoring http.ErrServerClosed; (7) log slog.Info("abysslinkd: metrics listening", "addr", addr); (8) block on <-ctx.Done(); (9) shut down with context.WithTimeout(context.Background(), 400*time.Millisecond) (defer cancel after the withTimeout call).
