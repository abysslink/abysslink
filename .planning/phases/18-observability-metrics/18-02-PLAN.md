## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-05 | Information Disclosure | GET /metrics binding address | mitigate | startMetricsServer resolves tailnet IP via backend.Client.IP — never binds 0.0.0.0; config.Validate (Plan 01) rejects invalid BindAddr at load time |
| T-18-06 | Information Disclosure | GET /status rig_id field | mitigate | RigID = OpaqueRigLabel(hostname) — 16-char hex, no raw hostname, IP, node_id exposed (OBS-04) |
| T-18-07 | Denial of Service | Prometheus label value injection via metric HELP strings | accept | HELP/TYPE strings are hardcoded constants in Registry.Register — not user-supplied; no label value injection vector in the hand-rolled formatter |
| T-18-08 | Elevation of Privilege | Metrics TCP port accessible to non-tailnet peers | mitigate | Listener binds to tailnet IP (100.64.x.x or fc00::x); tailnet firewall restricts access; FATAL metrics-bind-tailnet doctor check (Plan 03) rejects misconfiguration |
| T-18-09 | Tampering | Stale metrics listener after disable | mitigate | Shutdown(400ms) on ctx cancel; met-disabled-listener doctor probe (Plan 03) detects if port stays open |
| T-18-SC | Tampering | npm/pip/cargo installs | accept | No new external packages; all stdlib |
