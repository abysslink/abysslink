## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user → --binary-path | User-supplied binary; version gate + SHA-256 checksum enforced before install |
| abysslink → container runtime | Container port binds MUST include 127.0.0.1 prefix (loopback-only) |
| abysslink → systemd | Service unit specifies User=netbird-server (non-root) |
| CLI output → secrets | API key / setup key must never appear in CLI output or audit log |
| netbird init → ZITADEL admin API | Post-provision CVE probe: HTTP 401 or count==0 = PASS; HTTP 200 with results = FAIL+refuse |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-04-01 | Tampering | User-supplied --binary-path binary (PR-B) | mitigate | SHA-256 checksum computed + logged; version floor enforced before copy; checkpoint:human-verify (Linux) before activation |
| T-13-04-02 | Spoofing | Container port exposed beyond loopback | mitigate | `docker run -p 127.0.0.1:PORT:PORT` enforced on all three ports; nb-mgmt-bind check validates after provisioning; checkpoint:human-verify (macOS) confirms HostIp=127.0.0.1 via docker inspect |
| T-13-04-03 | Elevation of Privilege | netbird-server running as root | mitigate | systemd unit writes User=netbird-server; useradd --system creates non-login service user; macOS: container User verified via inspect; nb-proc-user check validates Linux; nb-runtime validates macOS |
| T-13-04-04 | Info Disclosure | API key exposed in CLI output or audit log | mitigate | Key never passed to Printer or slog; audit.WriteFile writes path+hash only; user instructed to store in keychain |
| T-13-04-05 | Tampering | Downgrade to pre-CVE version | mitigate | upgrade subcommand refuses if new version < current version; nb-version doctor check enforces floor |
| T-13-04-06 | Elevation of Privilege | Version below CVE floor provisioned | mitigate | init refuses with hard error if binary reports version < v0.57.0 |
| T-13-04-07 | Elevation of Privilege | ZITADEL default admin credential still active post-provision (CVE-2025-10678) | mitigate | Init-time inline probe (SC-2): POST /management/v1/users/_search after health-check; HTTP 200 with results causes hard FAIL + provisioning refused; Dex deployments log SKIP |
