    Implement `NetBirdDoctorChecks(ctx context.Context, cfg *config.Config, runner shell.Runner, doReq doRequestFunc) []DoctorFinding` returning exactly 8 findings, one per check:

    `checkNbTLS(cfg)` — parse cfg.Server.NetBird.ConfigPath (config.yaml), read server.tls.certFile and server.tls.keyFile. If both are set: use `crypto/tls.LoadX509KeyPair` + `x509.ParseCertificate` — cert must not be expired, CN/SAN must match cfg.Server.NetBird.ServerURL host. PASS if valid. FAIL if expired or key missing. If both are empty: FAIL (TLS required — nb-tls). Mirrors `checkHsTLS()` from headscale_doctor.go.

    `checkNbVersion(ctx, runner, binaryPath string)` — runner.Run(ctx, binaryPath, "--version"). Parse output for semver (versionRe pattern). Compare to floor "0.57.0" via semverLessThan helper (can be the same helper from headscale_doctor.go or a local copy). FAIL if below floor. PASS if at/above. WARN if binary not found or parse fails (binary may not be installed yet on macOS/container path). binaryPath = cfg.Server.NetBird.BinaryPath (container path on macOS: skip with DoctorOK "nb-version: macOS container path — version enforced by image tag").

    `checkNbZitadel(ctx, cfg, doReq)` — detect-then-probe per D-02: (1) read config.yaml server.auth.issuer; if strings.Contains(issuer, "zitadel") == false → return DoctorOK{Check:"nb-zitadel", Message:"no ZITADEL deployment detected — SKIP"}. (2) If ZITADEL detected: POST {issuer_base}/management/v1/users/_search with body `{"queries":[{"userNameQuery":{"userName":"zitadel-admin@","method":"TEXT_QUERY_METHOD_STARTS_WITH"}}]}`, header `Authorization: Bearer` (ZITADEL probe, NOT the NetBird Token — this is the ZITADEL admin API, not the NetBird API). Parse response: if HTTP 401 or result count==0 → PASS. If HTTP 200 and result count > 0 → FAIL "ZITADEL default admin account still active (CVE-2025-10678)".

    `checkNbMgmtBind(cfg)` — read config.yaml metricsPort (numeric) and check if it is bound to 0.0.0.0. In netbird-server config.yaml, metricsPort is just a port number (9090 default) — the bind address is ALWAYS localhost. The check is: if metricsPort > 0 AND config.yaml has any explicit `metricsListenAddress` field containing "0.0.0.0" → FAIL. Otherwise PASS. Also check: if cfg.Server.NetBird.MgmtBindAddr contains "0.0.0.0" → FAIL (config-level guard). Note from RESEARCH anti-patterns: server.listenAddress is expected to be `:443` for functionality; only metrics and admin ports are loopback-gated.

    `checkNbKeyType(ctx, doReq)` — GET /api/setup-keys. For each active key (not revoked, not expired): if key.Type != "one-off" → FAIL "setup key {id} is reusable — must be one-off (nb-key-type)". If key.Expires is zero or past → FAIL "setup key {id} has no expiry or is expired". If all keys pass → PASS. If no active keys → WARN "no active setup keys found".

    `checkNbAPIAuth(ctx, doReq)` — GET /api/groups. HTTP 200 → PASS. HTTP 401/403 → FAIL "API authentication failed (nb-api-auth)". Network error → WARN.

    `checkNbProcUser(ctx, runner)` — on Linux (runtime.GOOS=="linux"): runner.Run(ctx, "systemctl", "show", "netbird-server", "--property=User"). Parse "User=" value. Non-empty and != "root" and != "0" → PASS. Empty or root → FAIL. Service not found → WARN. On macOS (runtime.GOOS=="darwin"): return DoctorOK{Message: "nb-proc-user: macOS uses container path — process user enforced by container runtime (nb-runtime)"}.

    `checkNbRuntime(ctx, runner)` — on macOS (runtime.GOOS=="darwin"): probe for docker, colima, or podman binary via runner.Run(ctx, "docker", "info") (or colima/podman equivalent). If any returns exit 0 → PASS "container runtime {name} present and reachable". If all fail → FAIL "no container runtime found — required for NetBird server on macOS (nb-runtime)". On Linux: return DoctorOK{Check:"nb-runtime", Message:"nb-runtime: Linux uses native binary — SKIP"}.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config.yaml → MergeNetBirdConfig | Input file from filesystem; must not contain secret values |
| NetBird REST API → doctor checks | TLS enforced; doRequestFunc injectable for tests |
| ZITADEL probe → external ZITADEL admin API | Separate from NetBird API; uses Bearer header not Token |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-03-01 | Info Disclosure | config.yaml secrets | mitigate | MergeNetBirdConfig never writes API keys or setup keys to config.yaml — keychain-only per CLAUDE.md |
| T-13-03-02 | Elevation of Privilege | ZITADEL default admin (CVE-2025-10678) | mitigate | nb-zitadel detect-then-probe: FAIL if default admin account still active (HTTP 200 response from _search); D-02 logic implemented per spec |
| T-13-03-03 | Spoofing | Management port exposed to public (0.0.0.0) | mitigate | nb-mgmt-bind: FAIL if metricsListenAddress contains 0.0.0.0; config-level MgmtBindAddr also checked |
| T-13-03-04 | Elevation of Privilege | Setup key reuse enabling unauthorized enrollment | mitigate | nb-key-type: FAIL if any active key type!="one-off" or expires is zero/past |
| T-13-03-05 | Elevation of Privilege | NetBird server process running as root | mitigate | nb-proc-user: FAIL on Linux if systemctl User is root; macOS defers to container runtime |
| T-13-03-06 | Tampering | Unverified netbird-server binary version | mitigate | nb-version: hard FAIL if below v0.57.0 floor (CVE-2025-10678 fix boundary) |
| T-13-03-07 | Spoofing | TLS disabled or invalid cert | mitigate | nb-tls: FAIL if no cert configured or cert expired/mismatched; mirrors hs-tls strict behavior |
| T-13-03-SC | Tampering | npm/pip/cargo installs | accept | No package manager installs in this plan |
