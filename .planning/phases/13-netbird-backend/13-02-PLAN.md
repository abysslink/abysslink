## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| adapter → NetBird REST API | TLS required; apiKey injected only into Authorization header |
| Up() → tailscale CLI | Setup key injected via env (TS_AUTHKEY), never argv |
| Validate() → NetBird REST API | Re-read after push; content mismatch is FAIL not warning |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-02-01 | Info Disclosure | API key (ABYSSLINK_NB_API_KEY) | mitigate | apiKey() reads env on each call; never stored as plain field; never passed to slog/audit/argv; header set only inside doRequest() |
| T-13-02-02 | Info Disclosure | Setup key (ABYSSLINK_NB_SETUP_KEY) | mitigate | Read from env var only; injected via RunWithEnv TS_AUTHKEY; never in args slice; never logged |
| T-13-02-03 | Tampering | Silently dropped ACL rule | mitigate | Validate() enforces full content equality (count + normalized rule bodies) immediately after PushDenyAllBaseline; mismatch returns error (D-08, SC-3) |
| T-13-02-04 | Elevation of Privilege | "All" group allow-all policy left active | mitigate | RemoveAllowAllPolicies called before PushDenyAllBaseline; SC-1 ordering enforced in Up() |
| T-13-02-05 | Spoofing | Wrong Authorization header (Bearer vs Token) | mitigate | doRequest hardcodes `"Token "` prefix — NEVER "Bearer " (RESEARCH Anti-Patterns, auth_middleware.go verified) |
| T-13-02-06 | Elevation of Privilege | Reserved "All" group created by EnsureGroup | mitigate | EnsureGroup returns error if name=="All"; system group found only by issued==system |
| T-13-02-SC | Tampering | npm/pip/cargo installs | accept | No package manager installs in this plan — stdlib + existing go.mod only |
