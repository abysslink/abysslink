<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller→Registry.Open() | Declared tier can be attacker-influenced if caller is compromised; in-code CriticalPatterns enforces floor regardless |
| capability URL holder→daemon | Possession of an approve/deny URL is the bearer capability; 256-bit entropy makes guessing infeasible |
| concurrent goroutines→pendingReq.state | Two concurrent resolution attempts race on the CAS primitive |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-01 | Spoofing | SignApproveURL/VerifyApproveURL | mitigate | HMAC-SHA256 with audit-hmac keychain key (D-16); hmac.Equal constant-time compare prevents timing oracle |
| T-30-02 | Tampering | Tier() action-name matching | mitigate | CriticalPatterns is an immutable in-code var; extraCritical is appended, never replaces; callers cannot downgrade a critical action (D-08) |
| T-30-03 | Elevation of privilege | Tier downgrade via caller declaration | mitigate | Tier() takes max of declared and in-code match; critical always wins |
| T-30-04 | Denial of service | Registry.pending map growth | mitigate | Prune after Wait returns; bounded by Open rate (rate-limited by the gate call sites, not by the registry itself) |
| T-30-05 | Tampering | Late approve after deny (deny-then-late-approve race) | mitigate | CAS CompareAndSwap(statePending, newState): state already set → returns false; the pending→denied transition is terminal (APPR-02) |
| T-30-06 | Information disclosure | Capability URL logged in approve package | mitigate | Log only requestID prefix (8 chars) and tier; never log full requestID, URLs, or hmacSig. No fmt.Println (CLAUDE.md) |
| T-30-SC | Tampering | npm/pip/cargo installs | accept | No new external packages in this plan — stdlib + testify (already in go.mod); no install tasks |
