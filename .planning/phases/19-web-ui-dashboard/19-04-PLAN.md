## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| daemon startup → webui goroutine | The webui server is a goroutine in the daemon process; crashes must not kill the daemon |
| notify event → ring buffer | NotifyEvent written to ring must not include secret bodies (AUD-04 consistent) |
| operator → doctor check output | Doctor check messages must describe failure class only; no key material in messages |
| webui-csrf live probe → running daemon | Doctor probe uses insecure TLS skip but is operator-initiated read-only check |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-17 | Information Disclosure | webui-csrf/webui-csp live probe via doctor | mitigate | Doctor probe uses InsecureSkipVerify HTTP client (not the browser-facing TLS path); probe is operator-initiated read-only check; no credentials sent |
| T-19-18 | Denial of Service | webui goroutine panic crashing daemon | mitigate | StartWebUIServer goroutine has deferred recover (Plan 02); slog.Error on recovery; daemon process continues unaffected |
| T-19-19 | Information Disclosure | NotifyEvent bodies in ring buffer | mitigate | Ring stores only Title, Topic, Priority, Time — no notification body content (consistent with AUD-04: no secret bodies in observable surfaces) |
