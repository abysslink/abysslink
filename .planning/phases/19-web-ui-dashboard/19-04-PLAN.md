<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| daemon startup → webui goroutine | The webui server is a goroutine in the daemon process; crashes must not kill the daemon |
| notify event → ring buffer | NotifyEvent written to ring must not include secret bodies (AUD-04 consistent) |
| operator → doctor check output | Doctor check messages must describe failure class only; no key material in messages |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-17 | Information Disclosure | webui-csrf/webui-csp live probe via doctor | mitigate | Doctor probe uses insecure HTTP client (not the browser-facing TLS path); probe is operator-initiated read-only check |
| T-19-18 | Denial of Service | webui goroutine panic crashing daemon | mitigate | StartWebUIServer is in a goroutine with deferred recover; slog.Error on error; daemon continues; the webui goroutine restarts on next daemon restart only |
| T-19-19 | Information Disclosure | NotifyEvent bodies in ring buffer | mitigate | Ring stores only Title, Topic, Priority, Time — no notification body content (consistent with AUD-04: no secret bodies in observable surfaces) |
| T-19-20 | Elevation of Privilege | webui reads doctor findings without WhoIs re-auth | accept | The HTTP request already passed WhoIs middleware at the outer handler layer; handleDoctor runs within that authenticated context |
| T-19-21 | Tampering | CSP header not set when safeweb bypassed | mitigate | safeweb.Server is the handler for ALL routes (BrowserMux wraps mux); CSP is set by safeweb on every response; TestCSPHeader asserts the header is present |
| T-19-SC | Tampering | npm/pip/cargo installs | mitigate | No npm install in Go build; htmx is a one-time curl download vendored as a static file; SRI verification at make check-htmx-sri |
</threat_model>
