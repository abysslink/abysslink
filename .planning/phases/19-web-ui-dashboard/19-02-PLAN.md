<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tailnet peer → WhoIs middleware | Every request from a tailnet peer crosses this boundary; WhoIs is the identity gate |
| loopback → WhoIs middleware | No loopback address may pass; 403 is the only response (WEB-04 HARD FLOOR) |
| non-GET request → readOnlyMiddleware | All mutation methods blocked unless explicitly unlocked (WEB-02 HTTP layer) |
| htmx form POST → safeweb BrowserMux | CSRF token required; safeweb rejects token-absent POSTs (WEB-05) |
| audit.Entry → AuditEntryView projection | Hash/PrevHash/Sig fields must never cross this boundary into templates |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-04 | Elevation of Privilege | whoIsMiddleware loopback bypass | mitigate | ip.IsLoopback() check is the FIRST guard before WhoIs call; automated TestLoopback403 asserts 403; no code path bypasses it |
| T-19-05 | Spoofing | WhoIs auth — nil UserProfile | mitigate | Explicit nil check on info.UserProfile before accessing LoginName; TestWhoIsNilProfile403 covers this |
| T-19-06 | Tampering | CSRF on allow_notify POST | mitigate | safeweb BrowserMux wraps all routes; gorilla/csrf inside safeweb rejects missing tokens; TestCSRFMissing403 asserts 403 |
| T-19-07 | Information Disclosure | audit hash/chain leak via AuditEntryView | mitigate | AuditEntryView struct has no Hash/PrevHash/Sig fields by construction; TestAuditProjection asserts absence; no cast to audit.Entry possible from template |
| T-19-08 | Information Disclosure | base binary SDK/webui symbol leak | mitigate | //go:build webui on every file; make check-webui-isolation + check-webui-build-tags CI gates; failing either blocks merge |
| T-19-09 | Denial of Service | GetCertificate lazy failure on Headscale | mitigate | Backend type check in module.go Verify() fires webui-tls FATAL before listener binds; TestTLSProbeFailClose asserts no listener bound; no plaintext fallback |
| T-19-10 | Spoofing | Stale TLS cert served | accept | lc.GetCertificate auto-refreshes via Tailscale daemon; no manual cert management; risk is extremely low |
| T-19-18 | Denial of Service | webui goroutine panic crashing daemon | mitigate | First statement of StartWebUIServer goroutine is deferred recover; slog.Error on recovery; daemon process continues |
| T-19-SC | Tampering | tailscale.com module | mitigate | Approved in RESEARCH.md Package Legitimacy Audit; go.sum locks the hash |
</threat_model>
