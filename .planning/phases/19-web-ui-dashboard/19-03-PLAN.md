<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| template rendering → HTML output | html/template auto-escaping is the XSS gate |
| audit.ReadLog → AuditEntryView | Projection struct prevents Hash/PrevHash/Sig reaching templates |
| /static/ handler → embed.FS | Static assets served from same-origin embed.FS; no user-controlled path |
| browser → CSP enforcement | CSP default-src 'self' blocks any external resource fetch by the browser |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-11 | Tampering / XSS | html/template rendering of audit.Entry fields | mitigate | AuditEntryView projection struct structurally prevents Hash/PrevHash/Sig; html/template auto-escapes all .Field values; text/template import is gosec G203 violation |
| T-19-12 | Tampering / CSP bypass | inline style= attributes in templates | mitigate | CSP default-src 'self' blocks inline styles at browser level; grep gate in verify section asserts zero style= matches in templates |
| T-19-13 | Information Disclosure | audit log body/content leak | mitigate | AuditEntryView has no body/content/data/raw fields by construction (AUD-04 HARD FLOOR) |
| T-19-14 | Tampering | CDN script injection via template src | mitigate | grep gate in verify asserts zero https:// in templates; CSP blocks external origins; htmx SRI prevents tampered local copy |
| T-19-15 | Information Disclosure | WhoIs LoginName PII beyond display name | accept | Template receives only LoginName string (not Node.Addresses or other PII per WEB-07); exposure is intentional and minimal |
| T-19-16 | Tampering | CSRF token lost on htmx partial swap | mitigate | Every form fragment (allow_notify form) includes CSRFTemplateField; safeweb cookie is the server-side source of truth |
| T-19-SC | Tampering | htmx.min.js vendored file integrity | mitigate | make check-htmx-sri verifies SHA-384 at build time; SRI attribute in script tag enforces at browser level |
</threat_model>
