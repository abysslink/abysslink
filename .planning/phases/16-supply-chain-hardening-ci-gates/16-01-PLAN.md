<task type="auto">
  <name>Task 1: Create security.yml PR scan gate workflow</name>
  <files>.github/workflows/security.yml</files>
  <action>
Create `.github/workflows/security.yml` as a brand-new workflow (do not modify test.yml or lint.yml). It triggers on `pull_request` targeting `main` only. Use three jobs, each with its own least-privilege permissions block:

**Job: harden (runs first, wraps the other jobs' runners)**
This job is a no-op orchestrator — it exists so that harden-runner appears at workflow level. Instead, apply `step-security/harden-runner` as the FIRST step in EACH of the three jobs below (this is the correct pattern: harden-runner is a step, not a wrapper job).

**Job: vuln-scan**
- `permissions: contents: read`
- `runs-on: ubuntu-latest`
- `timeout-minutes: 15`
- Steps:
  1. `step-security/harden-runner` (per D-01, version pinned to SHA for v2.17.0; egress-policy: block; allowed-endpoints includes `golang.org:443 proxy.golang.org:443 sum.golang.org:443 vuln.go.dev:443 api.github.com:443`)
  2. `actions/checkout` pinned to SHA (use the SHA of v4.2.2: `11bd71901bbe5b1630ceea73d27597364c9af683`)
  3. `actions/setup-go` pinned to SHA (use SHA of v5.5.0: `0aaccfd150d50ccba258e0b4c4cb4579b3c4c47`)
  4. Install govulncheck: `go install golang.org/x/vuln/cmd/govulncheck@latest`
  5. Run: `govulncheck -mode=module ./...` — module mode reports ALL vulnerabilities in the dep graph regardless of reachability (per PITFALLS.md §Pitfall 16 — module mode catches dormant vulns that call-graph mode misses)
  6. Fail-on-findings: govulncheck exits non-zero on any finding; no additional grep needed

**Job: semgrep**
- `permissions: contents: read`
- `runs-on: ubuntu-latest`
- `timeout-minutes: 15`
- Steps:
  1. `step-security/harden-runner` (same SHA as above; egress-policy: block; allowed-endpoints includes `semgrep.dev:443 api.github.com:443`)
  2. `actions/checkout` (same pinned SHA)
  3. `returntocorp/semgrep-action` pinned to SHA of v1.1.0 (`38119e7e65b5e7b12a8a5f30bba91e6f65cad4c`); config: `p/r2c-security-audit p/golang`; generate-sarif-file: false (no SARIF upload — just fail the PR)
  - Semgrep exits non-zero on any finding. Do NOT use `continue-on-error`.

**Job: dep-review**
- `permissions: contents: read`
- `runs-on: ubuntu-latest`
- `timeout-minutes: 10`
- Steps:
  1. `step-security/harden-runner` (same SHA; egress-policy: block; allowed-endpoints includes `api.github.com:443 ghcr.io:443`)
  2. `actions/checkout` (same pinned SHA)
  3. `actions/dependency-review-action` pinned to SHA of v4.7.1 (`38b1093fc0fe41bb30ff53def22f96d5e9d62bef`); with:
     - `fail-on-severity: moderate`
     - `deny-licenses: AGPL-1.0-only, AGPL-1.0-or-later, AGPL-3.0-only, AGPL-3.0-or-later, GPL-2.0-only, GPL-2.0-or-later, GPL-3.0-only, GPL-3.0-or-later`
     - `comment-summary-in-pr: true`

Add the standard license header at the top:
```
# SPDX-License-Identifier: Apache-2.0
# Copyright 2026 Abysslink Contributors
```

Set `FORCE_JAVASCRIPT_ACTIONS_TO_NODE24: true` as a top-level env var (matches existing workflow convention).

IMPORTANT: All action `uses:` entries MUST use full commit SHA form `action/name@SHA`, NOT `action/name@v4` tag form. Tags are mutable. This enforces the per D-05 (SCH-05) pinned-SHA requirement.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR author → CI runner | Untrusted code runs govulncheck/semgrep/dep-review; action exfiltration via network |
| GitHub Actions OIDC → action steps | Egress-uncontrolled step could exfiltrate GITHUB_TOKEN |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-01 | Tampering | actions/checkout mutable tag | mitigate | pin all actions to full commit SHA; dependabot auto-updates |
| T-16-02 | Information Disclosure | govulncheck exfiltrating secrets via DNS | mitigate | harden-runner egress allowlist blocks non-allowlisted domains |
| T-16-03 | Elevation of Privilege | dep-review misses AGPL dep | mitigate | explicit deny-licenses list covers AGPL-1.0, AGPL-3.0, GPL-2.0, GPL-3.0 |
| T-16-04 | Denial of Service | semgrep OOM on large PR | mitigate | timeout-minutes: 15 per job kills runaway scans |
| T-16-SC | Tampering | npm/pip/cargo installs | accept | this phase adds no package-manager installs; govulncheck installed via `go install` (Go ecosystem, not npm) |
</threat_model>
