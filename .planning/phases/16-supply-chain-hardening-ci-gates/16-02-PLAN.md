**Reproducible build flags (SCH-06 / Pitfall 15):**

1. Add `-trimpath` as a build flag (not an ldflag). Add a `flags:` key under each build entry:
   ```

   ```
2. Change the ldflag `-X .../buildDate={{.Date}}` to `-X .../buildDate={{.CommitDate}}`. 4. Remove `-s -w` strip flags. Strip flags do NOT affect reproducibility (they strip debug symbols, not timestamps) — BUT they complicate SLSA provenance verification of embedded build metadata. Keep them if already present; do NOT add them if not. The existing file has them; leave them.

**Dual SBOM via syft (SCH-04):**

Replace the existing `sboms:` stanza entirely. The existing stanza only emits CycloneDX JSON. Replace with a stanza that emits BOTH SPDX-JSON and CycloneDX-JSON per artifact:

```yaml
sboms:
  - id: spdx
    artifacts: archive
    documents:
      - "${artifact}.spdx.json"
    args:
      - "${artifact}"
      - "--output"
      - "spdx-json=${document}"
  - id: cyclonedx
    artifacts: archive
    documents:
      - "${artifact}.cdx.json"
    args:
      - "${artifact}"
      - "--output"
      - "cyclonedx-json=${document}"
```

Both stanzas use `artifacts: archive` — one SBOM of each format per release archive file. The `args` format passes the artifact as the positional argument and writes the SBOM to the document path. Syft v1.44.0 (CI-only binary, installed via anchore/sbom-action) handles both formats natively with these args.

**Signs stanza (DO NOT change yet — Plan 03 updates signs to cosign v3 bundle):**
Leave the existing `signs:` stanza exactly as-is. Plan 03 will replace it for cosign v3.
