<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| --fix finding-to-path extraction | Finding.Message contains the flagged path; a crafted message could point --fix at a wrong file |
| audit.New(logPath).Append before os.Chmod | If Append fails, chmod must not proceed (do not silently skip the audit trail) |
| --pentest mode | Passing pentest=true to secDoctorFindings bypasses os.Getuid()==0 guard; must not be exploitable via non-interactive paths |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-03-01 | Tampering | --fix path injection via crafted Finding.Message | mitigate | sshd path guard: `strings.Contains(path, "sshd")` refuses; all --fix paths derived only from audit.DefaultLogPath() / config.Path() / daemon.SocketPath() — not from Finding.Message parsing. Emit the path from the check function directly, not parsed from text. |
| T-20-03-02 | Elevation of Privilege | --fix chmod daemon socket | mitigate | --apply gate (dry-run default); audit.New(logPath).Append records before chmod; restart note emitted |
| T-20-03-03 | Denial of Service | runAuditAggregate hangs if doctor sub-checks are slow | mitigate | ctx propagation: all sub-functions receive ctx; cancellation propagates |
| T-20-03-04 | Spoofing | audit aggregate "All checks passed" when chain not verified (keychain nil) | mitigate | runAuditVerify is called first; on nil keychain it already emits "HMAC checks SKIPPED" banner and returns exit 1 (WR-02); aggregate inherits this behavior |
| T-20-03-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this plan |
