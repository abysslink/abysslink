    4. Collect supply-chain findings: `supplyChainFindings(ctx, cc.runner, version, "")`
    5. Collect backend + fleet findings via `appendBackendAndFleetFindings`
    6. Concatenate all into `allFindings`. Dedup by check ID using `seen map[string]bool` — first occurrence wins.
    7. Severity roll-up: scan allFindings; any SeverityFatal → exit 2; any SeverityWarning → exit 1; else exit 0.

The --pentest flag is passed down to secDoctorFindings (or to readSSHEffectiveConfig) to allow sshd -T even when not root for explicit pentest runs. Add a `pentest bool` parameter to secDoctorFindings; when pentest=true, skip the os.Getuid()==0 guard on sshd -T.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| --fix finding-to-path extraction | Finding.Message contains the flagged path; a crafted message could point --fix at a wrong file |
| audit.Append before os.Chmod | If Append fails, chmod must not proceed (do not silently skip the audit trail) |
| --pentest mode | Passing pentest=true to secDoctorFindings bypasses os.Getuid()==0 guard; must not be exploitable via non-interactive paths |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

Emit the path from the check function directly, not parsed from text. |
| T-20-03-02 | Elevation of Privilege | --fix chmod daemon socket | mitigate | --apply gate (dry-run default); audit.Append records before chmod; restart note emitted |
