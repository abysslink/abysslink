<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sshd -T output → sec-ssh-* | Attacker controlling sshd output could spoof parsed values |
| /etc/ssh/sshd_config → parser | File with crafted keyword/value could confuse the scanner |
| platform.DiskEncryptionStatus → sec-disk-encryption | Platform must be a non-stub implementation for the check to be meaningful |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-02-01 | Tampering | sshd -T output injection | mitigate | Parsed with bufio.Scanner + SplitN(line, " ", 2); no shell eval; first token only used as keyword match |
| T-20-02-02 | Elevation of Privilege | sec-daemon-socket-perms: race between stat and chmod | accept | Check is read-only (stat only); the --fix chmod in Plan-03 is the write path; TOCTOU race during the stat is not exploitable without already having write access to the socket path |
| T-20-02-03 | Information Disclosure | sec-no-world-readable-config walking symlinks | mitigate | WalkDir uses os.DirEntry.Type(); regular files only (entry.Type().IsRegular()); symlinks not followed |
| T-20-02-04 | Spoofing | alias checks (sec-metrics-bind) re-running underlying checks | accept | The alias checks copy from pre-computed finding slices (run-once pattern from RESEARCH Pitfall 3 mitigation); no duplicate execution |
| T-20-02-05 | Denial of Service | WalkDir over a very large config directory | accept | Config dir is user's ~/.config/abysslink — not a large tree; abysslink controls the writes into it via audit.WriteFile |
| T-20-02-SC | Tampering | npm/pip/cargo installs | accept | No package installs; all code uses stdlib + existing in-repo packages |
</threat_model>
