## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Source code → CI lint gate | Suppression annotations are the attack surface; unjustified //nolint: could hide real findings |
| CI → gosec binary | gosec must be pinned to prevent supply-chain substitution |
| .semgrepignore → semgrep engine | Overly broad ignore patterns could hide real XSS in future templates |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-01-01 | Spoofing | nolintlint gate bypass | mitigate | nolintlint require-specific:true prevents //nolint (no linter named); require-explanation:true prevents bare //nolint:gosec |
| T-20-01-02 | Tampering | gosec suppression via #nosec without justification | mitigate | gosec accepts #nosec without explanation; CI gosec job exits non-zero on any unsuppressed finding — only existing #nosec (signed.go G115) is grandfathered |
| T-20-01-03 | Information Disclosure | overly broad .semgrepignore | mitigate | .semgrepignore scoped to internal/modules/webui/templates/ only — not the entire webui package |
| T-20-01-04 | Tampering | unpinned gosec @latest in CI | mitigate | Pin gosec at v2.21.4 via go install; same pattern as govulncheck pinning in the existing vuln-scan job |
| T-20-01-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this plan; gosec installed via go install (Go module checksum verified) |
