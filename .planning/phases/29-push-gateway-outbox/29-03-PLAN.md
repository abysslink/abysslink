<objective>
Implement the FCM gateway leg (PUSH-04) using raw FCM HTTP v1 (resolved by D-02
binary-delta spike: the firebase SDK added 16 MB vs near-zero for raw HTTP). The
`FCMGateway` uses `golang.org/x/oauth2/google.CredentialsFromJSON` for OAuth2
service-account token acquisition with auto-refresh, and POSTs a data message
(not a notification message) with `android.priority = "high"` to defeat Android Doze.
The FCM project_id is derived from the service-account JSON (research Q2) rather than
a separate config field, avoiding config drift.

This plan runs parallel to 29-02 (no file overlap) — both implement the `Gateway`
interface from 29-01.

Purpose: Completes the three provider legs. Together with 29-02, all Gateway
implementations exist before the daemon wiring (29-04).

Output: `fcm.go` + `fcm_test.go`; green `make lint test`.

|----------|-------------|
| FCMGateway → fcm.googleapis.com | Only opaque data message (routing metadata, no pane text) crosses this boundary |

| OAuth2 token → Authorization header | Access token auto-refreshed by x/oauth2 TokenSource; not stored separately |
