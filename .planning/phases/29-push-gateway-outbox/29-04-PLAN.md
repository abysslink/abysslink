<objective>
Wire all Phase 29 components into the running daemon. This plan: (1) extends the
config struct with `notify.gateway.*` keys (APNs/FCM default disabled, D-14);
(2) extends the daemon composition root to open the bbolt outbox and construct all
three Gateway legs; (3) extends the notify dispatcher to fan out to all enrolled
devices using CollapseID and the Outbox for durable delivery (D-10, D-09);
(4) adds an outbox retry goroutine with exponential+full-jitter backoff (D-08),
dead-token pruning (D-12), and dedup suppression (D-07); (5) adds gateway/outbox
counters to GET /status (D-19); (6) emits experimental startup warnings for
APNs/FCM when enabled (D-14).

Purpose: After this plan, the complete push pipeline is live: notify event →
fan-out to enrolled devices → Outbox → retry goroutine → provider send → receipt.
UnifiedPush is the default-on path; APNs/FCM are wired but disabled by default.

Output: Updated config, dispatch, server, and main.go; new outbox_runner.go and
counters.go; green `make lint test`.
</objective>
