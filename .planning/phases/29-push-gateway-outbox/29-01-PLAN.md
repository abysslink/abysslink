<objective>
Establish the `internal/push` leaf package: Wire three new Go module dependencies
(bbolt v1.4.3, apns2 v0.25.0, oauth2 v0.36.0 explicit), define the `Gateway`

`CredsSource` interface with stub and mock implementations. Write unit tests for all
of the above.

implement (Gateway legs), and Plan 04 will wire into the daemon. Nothing in this plan
calls real providers — the package is purely the interface + outbox + types.
