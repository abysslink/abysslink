## v3.0.1 Requirements

### Network Exposure (NET)

- [x] **NET-01** *(A1, CRITICAL, verified)*: The self-hosted ntfy server binds to the tailnet IP only — the Docker run path must NOT publish `127.0.0.1:<port>:80` (or any loopback/`0.0.0.0` mapping); a `doctor` check fails closed if ntfy is reachable on any non-tailnet interface. `internal/modules/ntfy/module.go:401`.
- [x] **NET-02** *(A7, HIGH, verified)*: NetBird `server_url` is rejected at `config.Validate` unless it begins with `https://` (mirroring the existing Headscale guard), so the NetBird PAT is never transmitted over cleartext HTTP. `internal/config/config.go:629`.
- [x] **NET-03** *(A8, HIGH, verified)*: Config-supplied hostname and backend `server_url` values are validated (DNS-safe charset / leading-dash rejected) before being passed as argv tokens to `tailscale up`/`set`, preventing flag injection (e.g. `--advertise-exit-node`, `--login-server=…`). Reuse the `fleet.safeHostname` pattern; also covers the `daemon/server.go:333` tmux pane name. `internal/backend/{netbird,headscale}.go`, `internal/config/config.go:529`.

### Dependency & Toolchain (DEP)

- [x] **DEP-01** *(A2, HIGH, verified via govulncheck)*: The project builds on go1.26.4 — `go.mod` `go`/`toolchain` directives, `GOTOOLCHAIN`, and every CI workflow (release/security/repro/fuzz/test, currently pinned to 1.23) are aligned, closing reachable stdlib CVEs GO-2026-5039 (net/textproto) and GO-2026-5037 (crypto/x509).
- [x] **DEP-02** *(A3, HIGH)*: `golang.org/x/crypto` is bumped to ≥ v0.52.0 (the 2026-05-22 SSH security batch — 13 CVEs).
- [x] **DEP-03** *(A12, HIGH)*: The Web UI CSRF layer is migrated off the unmaintained `github.com/gorilla/csrf` (CVE-2025-47909, scheme-ignoring `TrustedOrigins`, no upstream fix) to stdlib `net/http.CrossOriginProtection` (Go 1.26); `gorilla/csrf` and `gorilla/securecookie` CSRF use is removed. Existing WhoIs/CSP/read-only gates preserved.

### Doctor Honesty & Coverage (DOC)

- [x] **DOC-01** *(A4, HIGH, verified)*: `abysslink threat-model` derives every row's ✓/✗ from the SAME full finding set as `abysslink doctor` (`collectDoctorFindings`), not just core-module `Doctor()`; rows whose backing check did not run render "unknown/—", never ✓. `internal/cli/cmd_threat_model.go:99`.
- [x] **DOC-02** *(A5, HIGH, verified)*: Disk-encryption verification fails CLOSED on tool error or unknown state — Linux `checkLUKS` emits FATAL when `lsblk` is missing/errors/unparseable (not `nil,nil`), macOS treats FileVault in-progress/deferred as not-fully-enabled, and `up`'s disk-encryption gate blocks on "unknown". `internal/modules/hardening/detect_linux.go:65`, `detect_darwin.go:61`.
- [x] **DOC-03** *(A6, HIGH, verified)*: The NetBird backend emits an unconditional `nb-lock` SeverityWarning (Tailnet Lock absent), mirroring the existing `hs-lock`, so the posture signal and the `threat-model` row are honest. `internal/backend/netbird_doctor.go:80`.
- [x] **DOC-04** *(C, HIGH)*: `doctor` surfaces a minimum-versions table that fails on known-vulnerable component versions — at minimum ntfy ≥ 2.21 FATAL (CVE-2026-39087 unauthenticated RCE, CVSS 9.8); structured to add Tailscale/tmux/mosh floors. Distinguishes vendored-stdlib CVEs from protocol CVEs.
- [x] **DOC-05** *(WR-02, MED)*: `funnelActive` (tailscale/module.go) distinguishes probe failure from confirmed-inactive — on exec error / non-zero exit it surfaces a distinct `funnel-probe-fail` SeverityWarning, never a `SeverityOK` funnel ✓. `internal/modules/tailscale/module.go`.
- [x] **DOC-06** *(WR-03, MED)*: `metBindTailnetCheck` (cmd_doctor.go) emits a `met-bind-unknown` SeverityWarning when the backend tailnet IP is unresolvable and a non-wildcard bind is configured, instead of a false OK. `internal/cli/cmd_doctor.go`.
- [x] **DOC-07** *(WR-04, MED)*: ntfy `listen_address` check flags IPv6 wildcard binds (`[::]:PORT`, bare `::`), mirroring `0.0.0.0` detection. `internal/modules/ntfy/module.go`.
- [x] **DOC-08** *(WR-08, MED)*: report-only `SeverityOK` findings emit exactly once per `abysslink doctor` pass for lock/ssh/ntfy/acl/tailscale (Verify no longer re-delegates to Detect); `TestRunnerDoctor_NoDoubleEmit` guards single-emission. `internal/modules/{tailscale,ntfy,lock,ssh}/module.go`.
- [x] **DOC-09** *(CR-02, MED)*: `serveActive` (tailscale/module.go) distinguishes serve-probe failure from confirmed-inactive — on exec error / non-zero exit `checkNoPublicExposure` surfaces a distinct `serve-probe-fail` SeverityWarning, so "No public exposure" never renders ✓ when the serve probe could not run.
- [x] **DOC-10** *(CR-01, MED)*: `metDisabledListenerCheck` (cmd_doctor.go) distinguishes a genuine closed port (`ECONNREFUSED` → SeverityOK) from an inconclusive dial error (timeout / unreachable / resolution failure → distinct `met-listener-unknown` SeverityWarning), so a stale-listener fail-closed control (OBS-05) never reports OK on an unproven probe.

### Audit Integrity (AUD)

- [x] **AUD-01** *(A9, HIGH, verified)*: Backups are bound to the tamper-evident HMAC chain — `Backup()` appends a signed audit entry recording the backup path + SHA-256, and `Restore`/`Reverse` recompute the backup's hash and require a match against a chain entry before writing, so backup tampering is detected. `internal/audit/{backup,reverse}.go`.
- [x] **AUD-02** *(A10, HIGH, verified)*: The audit log resists tail-truncation — the anchor is refreshed on every append (or a failed anchor write fails the operation), and a monotonic entry counter is pinned in the OS keychain so deleting the tail is detected by `Verify`. `internal/audit/{signed,anchor}.go`.

### DoS Resistance (DOS)

- [x] **DOS-01** *(A11, HIGH, verified)*: Every attacker-influenceable read is bounded — subprocess stdout capture is capped (e.g. 8–16 MiB, surfacing truncation as an error), the daemon `POST /notify` body uses `http.MaxBytesReader`, and all backend REST `Decode`/`io.ReadAll` calls (Headscale/NetBird/Tailscale-admin) wrap the body in `io.LimitReader`. `internal/shell/exec.go`, `internal/daemon/server.go:135`, `internal/backend/*`, `internal/tailscale/admin.go`.

### CI Gates (CI)

- [x] **CI-01** *(D-subset, HIGH-value)*: `govulncheck ./...` runs as a blocking CI gate (would auto-catch DEP-01/02/03 recurrence), and the two outlier workflows `lint.yml`/`test.yml` are brought to the repo's existing standard — actions pinned to full 40-char SHAs (no `version: latest`) + harden-runner.

## Deferred to v4.0.0 (Fortify) — NOT in this milestone

- **B (MED gaps):** Tailnet Lock WARN-only/skippable (B1), FileVault mid-encryption (B2 — partially covered by DOC-02), firewall stealth/Linux firewall checks (B3), REST client timeouts (B4), write/backup symlink-TOCTOU (B5), upgrade cross-host redirect (B6), htmx-SRI CI gate + `/notify` body limits (B7 — partially DOS-01), fleet HMAC framing (B8), ntfy topic entropy (B9), child-process env minimization (B10).
- **D (supply-chain depth):** OpenSSF Scorecard, Dependency Review, Syft+Grype/Trivy SBOM + VEX + attestation, GitHub Artifact Attestations → SLSA L3, SLSA v1.1 alignment, reproducible-build double-build diff, `GOFLAGS=-mod=readonly`.
- **E (at-risk-user threat model, P0–P2):** duress credential (E1), dead-man-switch/auto-revoke (E2), panic remote-session-kill + key rotation (E3), encrypt audit/backups at rest + metadata-minimize (E4), FIDO2/Secure-Enclave keys (E5), content-free notifications (E6), ephemeral/no-trace mode (E7), `doctor --profile at-risk` (E8), decoy config (E9), mlock/zeroize + HMAC-key rotation (E10), boot/device attestation (E11).
- **External version floors (proactive):** NetBird ≥ 0.57.0 (CVE-2025-10678), Tailscale ≥ 1.98.1 + statedir-when-locked (TS-2026-002 / TS-2025-008), EternalTerminal ≥ 6.2.0 + prefer-mosh, OpenSSH ≥ 10.0 PQ-KEX hardened fallback, SSH session recording `enforceRecorder:true`, ACL Grants + `tests:` blocks. (DOC-04 lays the doctor minimum-versions table these slot into.)
