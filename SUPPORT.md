# Support

## Questions and ideas

[GitHub Discussions](https://github.com/abysslink/abysslink/discussions) is the canonical place for setup help, "is this possible" questions, and design ideas. Search first — someone may have hit the same wall.

## Bugs and feature requests

Use the issue forms:

- [Bug report](https://github.com/abysslink/abysslink/issues/new?template=bug_report.yml)
- [Feature request](https://github.com/abysslink/abysslink/issues/new?template=feature_request.yml)
- [Experience report](https://github.com/abysslink/abysslink/issues/new?template=experience_report.yml) — how your setup went, good or bad

Before filing a bug, `abysslink doctor` and `abysslink logs --since 1h` usually narrow down the broken layer. Redact secrets before pasting anything.

## Security vulnerabilities

Never in a public issue or discussion. Use the private channels in [SECURITY.md](SECURITY.md).

## Response expectations

Abysslink is a solo-maintainer project. Issues and discussions are answered on a best-effort basis — usually within days, sometimes longer. Security reports get priority; see [SECURITY.md](SECURITY.md) for the acknowledgment window. There is no paid support and no SLA.
